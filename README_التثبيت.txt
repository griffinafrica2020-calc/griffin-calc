تطبيق Griffin Africa — حاسبة تكاليف الاستيراد
================================================

محتويات الحزمة:
- index.html            التطبيق الكامل (يعمل أوفلاين)
- manifest.webmanifest  ملف تعريف التطبيق
- sw.js                 مشغّل العمل أوفلاين بعد التثبيت
- icon-192.png / icon-512.png  أيقونات التطبيق

طريقة التحويل إلى تطبيق (مرة واحدة فقط):
1) ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub
   (نفس طريقتك مع HSQ Store) وفعّل GitHub Pages.
2) افتح الرابط من متصفح كروم على هاتفك.
3) من قائمة كروم (⋮) اختر: "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
4) سيظهر التطبيق بأيقونة جريفين على شاشة الهاتف، يفتح بملء الشاشة،
   ويعمل بدون إنترنت بعد أول فتح.

الأمان:
- زر القفل 🔒 في أعلى التطبيق يفعّل تشفير AES-256 لكل الحركات المحفوظة.
- بدون الرمز الصحيح لا يمكن قراءة البيانات حتى من ملفات المتصفح.
- تحذير: نسيان الرمز يعني فقدان البيانات — احتفظ بنسخة احتياطية
  (زر "نسخة احتياطية" داخل صفحة المحفوظات).
- ملف النسخة الاحتياطية غير مشفّر؛ احفظه في مكان آمن.

ملاحظات:
- مشاركة الصورة مباشرة إلى واتساب تعمل من رابط https بعد التثبيت.
- التحديث مستقبلًا: استبدل index.html في المستودع وغيّر اسم الكاش
  في sw.js (griffin-import-v2) ليصل التحديث للأجهزة.
